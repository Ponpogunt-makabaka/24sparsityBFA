### Monotonicity Analysis

#### Accuracy Behavior
- **Single accuracy increase**: Step 2 (92.14% vs 91.85% at step 1)
- **Magnitude**: +0.29% (small, likely due to eval noise/boundary effects)
- **Overall trend**: Strongly decreasing (92.33% → 11.67%)

#### Loss Behavior
- **Zero loss decreases**: Perfect monotonic increase
- **Loss progression**: 0.251 → 21.904 (smooth, no reversals)
- **Per-step ΔL**: Consistently positive (0.004 to 1.275 range)

### Evidence from Log
```

...
Step 50: | acc=11.67% loss=21.9039
```

### Why Step 2 Shows Acc Increase

**Hypothesis 1: Evaluation Noise**
- Calib subset (256 samples) ≠ eval subset (2000 samples)
- Small ΔL (0.004) could be within evaluation variance
- Model at boundary where 1-2 samples flip class

**Hypothesis 2: Benign Regularization Effect**
- Metadata flip may slightly improve generalization
- Loss still increases (monotonic), acc increase is incidental

**Conclusion**: This is NOT pathological non-monotonicity. Loss remains strictly increasing.

## Comparison: Proxy-Only vs Exact Verification

### Old T02 (Proxy-Only) - Historical Context
```
n_acc_increase_steps: 7 (multiple reversals)
n_loss_decrease_steps: Unknown (not logged)
Final acc: 30.37% (less effective)
```

### Root Cause of Old Non-Monotonicity
**Taylor Approximation Error**:
```python
proxy_score = w_fp * (g_new - g_old)  # First-order only
```
- Ignores higher-order terms
- Assumes linear loss landscape
- Actual loss may have curvature not captured

### Exact Verification Fix
```python
# For each top-K proxy candidate:
for candidate in top_k_candidates:
    apply_flip(model, candidate)
    new_loss = criterion(model(x_calib), y_calib)
    delta = new_loss - baseline_loss
    if delta > best_delta:
        best = candidate
    revert_flip(model, candidate)  # Restore state
```

**Guarantee**: Only accept flips that verifiably increase loss
